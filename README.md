# 沮授语音

《三国杀》沮授语音快捷播放页：按键盘 `1`–`4` 或点圆形按钮播放对应语音，可开关背景音乐并调音量。

在线地址：<http://8.138.120.241:6080/>

## 语音键位

| 按键 | 语音 |
|------|------|
| `1` | 渐营 |
| `2` | 渐营 |
| `3` | 矢北 |
| `4` | 阵亡 |

## 本地打开

用任意静态服务器打开本目录即可，例如：

```bash
npx serve .
```

或直接用浏览器打开 `index.html`（部分浏览器会对本地 `file://` 音频有限制，优先用静态服务器）。

## 文件

```text
index.html      页面
app.js          键盘 / 按钮 / 背景音乐
style.css       样式
bg.jpg          立绘（画框展示，同时作淡化背景）
bgm.mp3         背景音乐
audio/1.mp3 … 4.mp3   四句语音
legacy/         美化前的原版页面（index.html / app.js / style.css）
```

要看原版，用浏览器打开 `legacy/index.html`。
